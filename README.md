# Image Processing Based Smart Supermarket Product Identification System

A fully offline pipeline that takes a photo of multiple supermarket products
laid out on a table/basket, detects each product with classical OpenCV
image processing, classifies it with a locally fine-tuned MobileNetV2 model,
maps it to a supermarket category, and reports counts/statistics -- with
both a CLI (`main.py`) and an interactive Gradio web app (`gradio_app.py`).

No cloud APIs or online inference services are used anywhere in this project.

## Pipeline

```
Input Image
  -> Image Acquisition        (utils.py)
  -> Image Preprocessing       (preprocessing.py)
  -> Object Detection          (detection.py)
  -> Product Segmentation      (segmentation.py)
  -> Classification            (classification.py, MobileNetV2)
  -> Category Mapping          (category_mapping.py)
  -> Counting                  (statistics.py)
  -> Statistical Analysis      (statistics.py)
  -> Visualization             (visualization.py)
  -> Gradio Output             (gradio_app.py)
```


## Project Structure

```
SmartSupermarket/
  dataset/
    freiburg_groceries/   25 class folders of training images (see below)
    splits/                train.csv / val.csv / test.csv, generated by train_model.py
  images/                 your own basket/table test photos go here
  output/                 annotated images, charts, evaluation reports (generated)
  models/                 trained model (.keras) + class_indices.json (generated)
  report/                 university report source
  config.py               all tunables (paths, thresholds, hyperparameters) -- single source of truth
  utils.py                Module 1: image acquisition/validation
  preprocessing.py        Module 2: OpenCV preprocessing (resize/blur/threshold/morphology)
  detection.py            Module 3: contour-based object detection
  segmentation.py         Module 4: bounding-box cropping
  classification.py       Module 5: MobileNetV2 model + inference-time classifier
  category_mapping.py     Module 6: product -> supermarket category dictionary
  statistics.py           Module 7: counting + percentage statistics
  visualization.py        Module 8-10: annotated image, console report, bar/pie charts
  train_model.py          Training-only entry point (never imported by prediction code paths)
  predict.py              Prediction-only entry point (single crop -> name/confidence/category)
  evaluate.py             Test-set evaluation: accuracy, precision/recall/F1, confusion matrix
  gradio_app.py           Interactive web app (loads the trained model once, predicts only)
  main.py                 CLI: runs the full pipeline over images/
  requirements.txt
```
